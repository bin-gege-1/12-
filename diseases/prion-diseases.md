# 朊蛋白病 (Prion Diseases)

## 疾病概述

朊蛋白病（传染性海绵状脑病，TSEs）是一组**均一致死的神经退行性疾病**，由正常的细胞型朊蛋白（**PrP^C**）错误折叠为异常、蛋白酶抵抗型（**PrP^Sc**）引起。PrP^Sc 作为模板，将正常蛋白转化为更多朊蛋白，在脑内聚集并以类传染方式扩散。朊蛋白对标准热力、辐射和化学灭菌有极强抵抗力，不被抗生素或抗病毒药物影响。潜伏期从约 1 年到超过 **50 年**。克雅氏病（CJD）是最常见的朊蛋白病，年发病率约 1-2/百万。

## 流行病学

- **年发病率**: ~1-2/百万人年（全球稳定）
- **散发性 CJD (sCJD)**: ~85% 病例；自发性 PrP^C→PrP^Sc 转换或体细胞突变
- **中位发病年龄**: 约 60-68 岁（sCJD）
- **中位生存期**: ~5-8 个月（sCJD）；~90% 1 年内死亡
- **变异型 CJD (vCJD)**: 与食用 BSE 污染牛肉相关；更年轻发病、生存期稍长（~1-1.5年）
- **遗传性**: 5-15%（*PRNP* 基因突变）；GSS 和 FFI 进展较慢

## 病理特征

### 经典三联征（神经病理学确诊）
1. **海绵状空泡变性** — 神经毡中呈海绵样空洞
2. **神经元丢失** — 进行性神经元死亡
3. **星形胶质细胞增生** — 反应性星形胶质细胞增殖
4. **PrP^Sc 沉积** — 免疫组织化学证实

### 分子分型（sCJD 六亚型）
基于 **PrP^res 类型**（1型 21kDa / 2型 19kDa）和 **密码子 129 多态性**（MM/MV/VV）：

| 亚型 | 典型特征 |
|------|---------|
| **MM1/MV1** | 最常见；经典型快速进展性痴呆 + 肌阵挛 |
| **MM2-皮层** | 皮层为主，进展较慢 |
| **MM2-丘脑** | 散发性致死性失眠表型；丘脑变性 |
| **MV2** | 共济失调为主，生长期较长 |
| **VV1** | 极罕见；年轻发病，缓慢进展 |
| **VV2** | 共济失调起病，相对快速进展 |

## 人类朊蛋白病分类

| 类型 | 病因 |
|------|------|
| **散发性 CJD (sCJD)** | ~85%；自发性 PrP 转换或体细胞突变 |
| **家族性/遗传性 CJD** | 常染色体显性 *PRNP* 突变（5-15%） |
| **医源性 CJD (iCJD)** | 污染手术器械、硬脑膜移植物、角膜移植、人源性生长激素 |
| **变异型 CJD (vCJD)** | BSE 污染牛肉；也可经输血传播 |
| **Gerstmann-Sträussler-Scheinker (GSS)** | *PRNP* 突变；缓慢进展共济失调 + 痴呆 |
| **致死性家族性失眠 (FFI)** | *PRNP* D178N 突变；顽固性失眠、自主神经功能障碍 |
| **散发性致死性失眠** | 自发型（MM2-丘脑 sCJD 亚型） |
| **Kuru** | 历史性：巴布亚新几内亚 Fore 族经仪式性食人习俗 |

## 临床表现

### 经典型 sCJD
- **快速进展性痴呆**（数周至数月内显著恶化）
- **肌阵挛**（几乎普遍，但常晚期出现）
- **小脑性共济失调**（首发表现中 ~34%）
- **视觉症状**（~15% 首发：视物模糊、皮层盲、视失认）
- **精神症状**（~14% 首发：人格改变、抑郁、精神病、激越）
- **语言障碍**: 失语、构音障碍
- **运动症状**: 僵硬、痉挛、运动不能

### 非典型/变异型表现
- **Heidenhain 变异型**（3.7-10%）：视觉为主——皮层盲、视失认
- **运动障碍模拟**: 帕金森综合征、皮质基底节综合征、PSP 样、舞蹈症
- **孤立性失语**、失用或执行功能障碍
- **听觉/前庭起病**: 耳鸣、听力丧失
- **卒中样**单瘫或偏瘫
- **vCJD**: 较年轻发病；显著精神/感觉症状；小脑体征普遍；病理见"花簇状斑块"

## 诊断方法

| 检查 | 灵敏度 | 特异度 | 备注 |
|------|--------|--------|------|
| **MRI (DWI/FLAIR)** | 80-98% | 92-97% | "皮层缎带征"和/或基底节/丘脑弥散受限 |
| **CSF RT-QuIC** | 89.5-97% | ~100% | MV2、VV1、MM2-丘脑亚型中灵敏度较低（44-78%） |
| **CSF 14-3-3 蛋白** | ~87-92% | 40-92% | 早期和某些亚型灵敏度较低 |
| **EEG** | 75-95% | 不定 | 周期性尖波复合波（PSWCs）——经典但不恒定 |
| **脑活检/尸检** | 100%（确诊） | 100% | 金标准；生前极少进行 |

## 治疗方法

> **无任何疾病修饰治疗。** 纯支持/姑息照护。

- **疼痛管理**（麻醉性镇痛药）
- **肌阵挛控制**（氯硝西泮、丙戊酸）
- **抗抑郁药**（情绪症状）
- **营养支持**和安全措施
- **预防感染**对卧床患者至关重要

### 在研方向
靶向朊蛋白传播、错误折叠蛋白清除和基因沉默方法（如抗 *PRNP* ASO）；多个治疗试验"即将展开"。早期诊断仍是试验入组的关键挑战。

## 预后与病程

- **均一致死**
- **典型 sCJD**: 6 个月内丧失自护能力；中位死亡 ~5-8 个月
- **>2 年生长期**与年轻发病、女性、密码子 129 杂合子、某些分子亚型相关
- **死亡原因**: 感染（肺炎最常见）、心力衰竭、呼吸衰竭

## 预防

- **散发性 CJD**: 无已知预防方法
- **医源性 CJD**: 一次性器械或专用朊蛋白消毒方案；1985 年起使用合成生长激素
- **vCJD**: 严格 BSE 控制；风险人群献血推迟
- **遗传性 CJD**: 受累家庭的遗传咨询
