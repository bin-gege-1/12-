# 进行性核上性麻痹 (Progressive Supranuclear Palsy, PSP)

## 疾病概述

PSP 是一种**原发性 tau 蛋白病**，由 **4-重复 (4R) tau 蛋白**在神经元和胶质细胞中异常聚集引起。该病由 Steele、Richardson 和 Olszewski 于 1964 年首次描述，是最常见的非典型帕金森综合征之一。PSP 的核心特征包括垂直性核上性凝视麻痹、早期姿势不稳和向后跌倒、轴性强直以及对左旋多巴反应差。**2024-2025 年发现**: "纯"PSP 病理（无 AD、路易小体、TDP-43 或血管共病理）仅见于约 **8-9%** 尸检病例——这对临床试验设计有重大影响。

## 流行病学

- **患病率**: 约 5-7/10 万
- **发病年龄**: 通常 60 多岁（范围 40-80+）
- **中位生存期**: 症状出现后 ~6-7 年（范围 2-17 年）
- **男女比例**: 大致相等
- **遗传**: 大多数为散发；与 **MAPT H1 单倍型** 强相关；罕见 MAPT 突变（家族性聚集）

## 病理特征

### 核心病理
| 特征 | 描述 |
|------|------|
| **蛋白病** | **4R tau** 在神经元和胶质细胞中聚集，形成球形神经原纤维缠结、神经毡线、**丛状星形胶质细胞**和卷曲小体（少突胶质细胞） |
| **大体病理** | 中脑萎缩（脑桥相对保留）、小脑上脚萎缩、黑质脱色、苍白球橘色变色 |
| **显微镜** | 球形 NFTs（直丝 ~12-15 nm，与 AD 的成对螺旋丝不同）；丛状星形胶质细胞 |
| **通常缺失** | 淀粉样斑块和路易小体（但共病理常见） |

### 主要受累区域
丘脑底核、黑质致密部、苍白球、上丘、导水管周围灰质、齿状核、脑桥、额叶皮层

### 病理生理模型
tau 错误折叠 → 聚集为不可溶丝状物 → 微管功能受损 → 神经元死亡。细胞间 **"类朊蛋白样"** 传播（经小胶质细胞释放/摄取）是主要治疗靶点假说。

### 2025 关键更新
**>90%** 的病理确诊 PSP 同时存在 AD、路易小体、TDP-43 或脑血管共病理，意味 tau 靶向单药治疗试验可能效果受限。

## 临床表现

### 经典型 PSP-Richardson 综合征 (PSP-RS)

| 域 | 表现 |
|----|------|
| **姿势不稳与跌倒** | **最早最特征性体征** — 第一年内不明原因向后跌倒（后退步态），"拉拽试验"阳性 |
| **眼球运动障碍** | **垂直性核上性凝视麻痹**（向下注视先于向上注视受累）；垂直扫视变慢；方波跳动；晚期完全眼肌麻痹。核上性 → VOR/闭目现象保留 |
| **帕金森综合征** | 中轴 > 四肢僵硬；运动迟缓；面具脸伴"震惊"表情；颈后伸（retrocollis）；**左旋多巴反应差或缺如**；静止性震颤少见 |
| **假性球麻痹** | 构音障碍（低音量单调言语）、吞咽困难、流涎、情感不稳（假性球麻痹——不自主哭笑） |
| **认知行为** | **额叶-执行功能障碍**: 处理速度慢、计划/排序受损、情感淡漠、脱抑制、具体思维。NPI 上 *高淡漠 + 低激越/焦虑* 可区分 PSP 与 AD (~85% 准确率)。"鼓掌征"常见。记忆早期相对保留 |
| **眼睑体征** | 眼睑退缩、眼睑痉挛、眼睑开闭失用 |
| **睡眠** | 失眠（常因僵硬/不适），RBD 可出现 |

### MDS-PSP 亚型

| 亚型 | 关键区分特征 | 预后 |
|------|-------------|------|
| **PSP-RS** | 经典型：早期跌倒 + VSGP + 中轴强直 | 中位生存 ~6-7 年 |
| **PSP-P** | 震颤、不对称起病、部分初期左旋多巴反应；可模拟 PD | 更长生长期 (~9+年) |
| **PSP-PAGF** | 步态冻结、言语/书写冻结、无早期震颤/僵硬/眼肌麻痹 | 最长生长期 (~11-15年) |
| **PSP-CBS** | 不对称肌张力障碍、失用、皮层感觉丧失、肌阵挛 | 不定 |
| **PSP-bvFTD** | 早期显著人格/行为改变；晚期帕金森综合征 | 不定 |
| **PSP-PNFA/AOS** | 孤立性运动言语障碍 | 不定 |

### 疾病时间线
- ~50% 患者 3 年内需步行辅助；~8 年轮椅/卧床
- 主要死因：吸入性肺炎、感染、制动并发症

## 诊断方法

- **临床诊断**: 基于 MDS 2017 标准进行亚型分类
- **MRI**: 中脑萎缩，矢状位 **"蜂鸟征"**（中脑被盖萎缩）和轴向 **"牵牛花征"**；MR 帕金森指数 (MRPI) 有助于区分 PSP 与 PD/MSA
- **tau-PET**: 研究阶段，可显示 tau 沉积
- **神经心理学评估**: 额叶执行功能下降
- **左旋多巴挑战试验**: 通常反应差

## 治疗方法

> **无疾病修饰治疗获批。** 管理为对症、多学科综合和姑息。

### 对症治疗

| 症状 | 选择 |
|------|------|
| **帕金森综合征** | 左旋多巴/卡比多巴试验（少数患者有适度短暂反应，PSP-P 反应较好） |
| **流涎** | 阿托品眼药水（舌下）、格隆溴铵、唾液腺肉毒素注射 |
| **眼睑痉挛/肌张力障碍** | **肉毒素注射**（局灶性肌张力障碍一线） |
| **假性球麻痹** | 右美沙芬/奎尼丁、SSRIs |
| **抑郁/情感不稳** | SSRIs（氟西汀、舍曲林）、三环类（阿米替林—兼助流涎和睡眠） |

### 非药物与支持治疗（CurePSP 共识）

| 域 | 干预 |
|----|------|
| **物理治疗** | 步态/平衡训练、防跌倒策略、**加重助行器**（防向后跌倒） |
| **言语治疗** | 吞咽评估、饮食质地调整、交流策略/辅助设备 |
| **营养/吞咽困难** | **PEG**（经皮胃造瘘管）— 口服摄入不安全或不足时 |
| **眼科** | 棱镜眼镜（复视）；人工泪液；太阳镜（畏光）；肉毒素（眼睑痉挛） |
| **姑息治疗** | 早期整合、预先照护计划、疼痛/分泌物/呼吸困难管理 |

### 在研疾病修饰治疗

| 药物 | 机制 | 状态 |
|------|------|------|
| **NIO752** | ASO — 抑制 *MAPT* mRNA / tau 蛋白合成 | I 期 |
| **OBP-601** (Censavudine) | 逆转录转座子抑制剂 | II 期阳性 → 进入 III 期；**获 FDA 快速通道** |
| **AZP2006** | 小胶质细胞调节/抗炎 | IIa 期 |
| **Fasudil** | Rho 激酶抑制剂 | II 期 |

> 既往抗 tau 单抗（tilavonemab、gosuranemab、bepranemab）虽可降低 tau 病理但**未显示临床疗效**，引发对胞外 tau 传播假说的质疑。目前方向转向 ASO、抗炎和转座子抑制。

## 预后与病程

- **进行性、不可治愈**
- **中位生存**: 6-7 年
- **死亡原因**: 吸入性肺炎（最常见）、感染、跌倒并发症
- **综合多学科对症照护**是当前照护标准
