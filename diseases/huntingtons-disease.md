# 亨廷顿病 (Huntington's Disease, HD)

## 疾病概述

亨廷顿病是一种**常染色体显性遗传**的进行性神经退行性疾病，由 4 号染色体上 *HTT* 基因的 **CAG 三核苷酸重复扩展** 引起。George Huntington 于 1872 年首次详尽描述。HD 以**纹状体（尾状核和壳核）** 和大脑皮层的进行性萎缩为特征，临床表现为经典的**三联征**：运动症状（舞蹈症）、认知下降和精神行为症状。该病**完全外显**（CAG ≥ 40），目前**无法治愈**。

## 流行病学

- **患病率**: 西欧裔约 3-7/10 万；亚洲和非洲人群中较低（~1/10 万）
- **中国**: 发病率约 1-2/10 万，可能因诊断不足被低估
- **发病年龄**: 通常 30-50 岁（成人型）；<20 岁为青少年型（约 5-10%）
- **预期寿命**: 症状出现后约 15-20 年
- **遗传模式**: 常染色体显性，每个子女有 50% 遗传风险
- **早现现象**: 父系遗传时 CAG 重复更易扩展，导致下一代发病更早

## 病理特征

### 遗传病因

| CAG 重复数 | 解读 |
|-----------|------|
| 10-26 | 正常（无疾病风险） |
| 27-35 | 可突变范围（本人无症状，但可能扩展至下一代） |
| 36-39 | 降低外显率（部分人发病） |
| ≥40 | **完全外显**（100% 将发病） |

CAG 重复越长，发病越早（负相关）。

### 突变亨廷顿蛋白 (mHTT) 毒性机制

1. **蛋白聚集** — mHTT 含异常多聚谷氨酰胺（PolyQ）链，形成核内和胞质毒性包涵体
2. **兴奋性毒性** — NMDA 受体过度激活，钙稳态失调
3. **线粒体功能障碍** — 呼吸链复合物 II 缺陷、能量代谢降低
4. **氧化应激** — ROS 增加
5. **快速轴突运输 (FAT) 中断** — 细胞器运输受损
6. **转录失调** — 干扰基因表达和翻译后修饰
7. **体细胞 CAG 扩展** — CAG 重复在患者一生中（尤其在纹状体神经元）持续扩展，当达到临界阈值（~150）时触发细胞死亡

### 受累脑区
- **纹状体（尾状核、壳核）**: 最早、最严重萎缩；GABA 能中型多棘神经元首先受累 → 间接通路抑制丧失 → 运动过度
- **皮层**: 深层皮层在后期退变
- 苍白球、丘脑、底丘脑核、小脑：后期不同程度萎缩

## 临床表现

### 1. 运动症状

| 分期 | 特征 |
|------|------|
| **早期** | **舞蹈症**（不自主、急促、舞蹈样动作）；坐立不安；精细运动协调障碍；扫视眼动异常 |
| **中期** | 舞蹈症加重 + 肌张力障碍；平衡障碍、频繁跌倒；构音障碍；吞咽困难 |
| **晚期** | 运动不能-强直综合征（舞蹈症减轻，被运动迟缓和僵硬取代）；痉挛；缄默；完全依赖 |

**青少年 HD (Westphal 变异型)**: 以帕金森综合征、僵硬、肌张力障碍和癫痫为主，舞蹈症轻微或缺失。

### 2. 认知症状
- 执行功能障碍（计划、组织、优先级排序能力下降）
- 处理速度减慢、注意力不集中
- 记忆力损害（尤其新学习）；远期记忆相对保留至晚期
- 认知灵活性缺失、持续行为
- 疾病感缺失（anosognosia）— 晚期
- 进展为皮层下痴呆

### 3. 精神行为症状
- **抑郁** — 最常见（高达 50% 患者）
- **焦虑和易激惹** — 常早于运动症状出现
- **情感淡漠** — 兴趣和动机严重丧失
- **强迫-冲动行为**
- **精神病** — 约 10% 出现类精神分裂症表现
- **自杀风险增高** — 无论症状前还是症状后均需主动筛查

## 诊断方法

1. **临床评估** — 神经系统检查（运动、认知、精神三域）
2. **家族史** — 常染色体显性遗传模式为关键线索
3. **基因检测（确诊）** — 血液检测计数 HTT 基因 CAG 重复数
4. **神经影像（辅助）** — MRI/CT 显示尾状核萎缩伴"盒子状"脑室（代偿性脑室扩大）；FDG-PET 早期显示纹状体低代谢
5. **预测性检测** — 对有风险的无症状个体可进行，但需在专业遗传咨询指导下进行（遵循 HDSA 协议）

## 治疗方法

> **目前无疾病修饰治疗/治愈方法。** 所有治疗为对症和多学科综合管理。

### 药物对症治疗

| 症状 | 药物选择 |
|------|----------|
| **舞蹈症** | **VMAT2 抑制剂**: 缬苯那嗪 (Valbenazine, FDA批准，每日一次)、氘代丁苯那嗪 (Deutetrabenazine)、丁苯那嗪 (Tetrabenazine)；二线：非典型抗精神病药（奥氮平、利培酮） |
| **运动迟缓/僵硬** | 左旋多巴、多巴胺激动剂、金刚烷胺 |
| **抑郁** | SSRIs、安非他酮、文拉法辛；CBT |
| **易激惹/攻击** | SSRIs、心境稳定剂（丙戊酸、卡马西平）、非典型抗精神病药 |
| **精神病** | 非典型抗精神病药（喹硫平、氯氮平、奥氮平） |
| **焦虑/OCD** | SSRIs、CBT |
| **肌张力障碍** | 肉毒素注射 |

### 非药物治疗
- **物理治疗** — 步态训练、平衡、力量维持、防跌倒
- **作业治疗** — 适应性设备、家居改造
- **言语-语言病理学** — 吞咽管理、交流辅助
- **认知康复** — 记忆辅助、环境结构化
- **营养支持** — 高热量易吞咽食物（体重下降常见）
- **心理支持** — 咨询、HD 互助组、照护者支持
- **姑息治疗** — 晚期舒适和尊严维护

### 在研疾病修饰策略

| 方法 | 机制 | 状态 |
|------|------|------|
| **ASO** | 降低突变 HTT 蛋白 | 试验结果混合 |
| **AMT-130** (AAV5-miHTT) | AAV 载体递送 microRNA 靶向 HTT | 最有希望的疾病修饰信号；**预计 2026 年申请 FDA** |
| **RNAi** | 等位基因特异性 siRNA 沉默突变 HTT | 临床前/早期临床 |
| **CRISPR/Cas9** | 切除或中断扩展的 CAG 重复区 | 仅临床前 |
| **锌指蛋白 (ZFP)** | 抑制 HTT 转录 | 早期临床前 |
| **Pridopidine** | Sigma-1 受体激动剂 | 研究性 |

## 预后与病程

- **病程**: 从症状出现到死亡约 15-20 年（青少年型更短，约 8-10 年）
- **死亡原因**: 并发症（吸入性肺炎、感染、跌倒相关损伤）；自杀
- **无法阻止进展**: 目前所有治疗仅改善症状和生活质量
- **希望所在**: AMT-130 基因治疗是目前最有前景的疾病修饰候选药物
