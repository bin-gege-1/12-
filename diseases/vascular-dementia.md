# 血管性痴呆 (Vascular Dementia, VaD)

## 疾病概述

血管性痴呆是**第二常见的痴呆类型**（仅次于 AD），占所有痴呆的 **10-20%**。VaD 是由脑血管疾病导致脑血流减少或中断引起的缺血性、低灌注性或出血性脑损伤所致。**混合病理（血管性 + AD 病理）是老年患者中的常态而非例外**，单纯 VaD 相对少见。VaD 的认知损害以**执行功能障碍**为突出特征，可有阶梯样恶化或波动性病程。与其他神经退行性痴呆不同，VaD 在一定程度上是**可预防**的。

## 流行病学

- **占痴呆总数**: 10-20%
- **发病年龄**: 通常 >65 岁；发病率随年龄增长急剧上升
- **主要风险因素**: 高血压（**最重要的单一风险因素**）、糖尿病、高脂血症、心房颤动、吸烟、肥胖、缺乏运动
- **性别**: 男性略多
- **卒中后痴呆**: 约 10% 首次卒中后、约 30% 复发性卒中后发生

## 病理特征

### 血管损伤类型

| 机制 | 描述 |
|------|------|
| **大血管病** | 主要动脉闭塞导致大范围梗死（多梗死性痴呆、关键部位单梗死性痴呆） |
| **小血管病** | 腔隙性梗死（3-15 mm）、白质病变/白质疏松（leukoaraiosis）、**Binswanger 病**——约占 VaD 的 50% |
| **低灌注** | 分水岭/边缘带梗死，由全身低血压或颈动脉狭窄引起 |
| **出血性** | 脑出血、蛛网膜下腔出血、脑淀粉样血管病（CAA） |
| **遗传性** | **CADASIL** (*NOTCH3* 突变)、CARASIL、MELAS、Fabry 病 |

### 分子机制
内皮功能障碍 → 血脑屏障破坏 → 慢性神经炎症 → NLRP3 炎症小体激活 → 氧化应激 → 白质脱髓鞘 → 神经网络连接中断 → 突触衰竭

## 临床表现

### 认知症状（皮层下模式为主）

| 域 | 表现 |
|----|------|
| **执行功能障碍** | 计划、组织、问题解决困难（VaD 的核心特征） |
| **注意力** | 注意力分散、思维变慢 |
| **记忆力** | **通常轻于 AD**；可能缺失；线索提示后常可改善 |
| **语言** | 词语流畅性下降、找词困难、失语（皮层卒中后） |
| **视空间** | 复杂视觉加工障碍 |

### 神经精神症状
- **情感淡漠**（早期突出特征）
- **抑郁**（比 AD 更常见）
- **情绪不稳/假性球麻痹**（强制性哭笑）
- 易激惹、激越、攻击行为
- 精神病（幻觉、妄想）

### 运动/躯体症状
- **步态障碍**（快速拖曳步；"下半身帕金森综合征"——血管性帕金森综合征）
- **假性球麻痹**（构音障碍、吞咽困难）
- 排尿障碍（尿失禁）
- 局灶性神经体征（偏瘫、视野缺损）

### VaD 与 AD 的关键鉴别

| 特征 | 血管性痴呆 | 阿尔茨海默病 |
|------|-----------|------------|
| **起病** | 突发或阶梯样（卒中后） | 隐袭、渐进 |
| **病程** | 阶梯样恶化，可有平台期 | 缓慢持续进展 |
| **执行功能** | 早期突出损害 | 后期受累 |
| **记忆力** | 较轻；线索提示有效 | 早期严重；快速遗忘 |
| **抑郁** | 更常见 | 较少见 |
| **神经体征** | 局灶体征常见 | 早期通常无 |
| **步态** | 早期步态障碍 | 晚期步态障碍 |

## 诊断方法

诊断三要素：
1. **认知损害**（常为皮层下/执行功能为主）
2. **影像学证实的脑血管病变**
3. **脑血管事件与认知下降的时间关联**

### 诊断流程

| 评估 | 内容 |
|------|------|
| **病史** | 认知症状起病/进展过程；卒中/心血管病史；动脉粥样硬化风险因素 |
| **认知测试** | MMSE、**MoCA**——通常呈斑片状缺陷（与 AD 的全局性下降不同）；执行功能突出受损 |
| **MRI（金标准）** | FLAIR: 白质高信号、腔隙性梗死；T2*/SWI: 微出血；DWI: 急性梗死 |
| **血液检查** | 血常规、血糖、HbA1c、血脂、甲状腺、维生素 B12、梅毒/HIV（如需要） |
| **颈动脉多普勒** | 评估颅外血管病变 |
| **心脏检查** | 超声心动图/ECG/Holter——心源性栓塞来源 |

## 治疗方法

> **无法治愈，但可干预。** 管理聚焦三大支柱。

### 1. 预防进一步血管损伤（风险因素控制——最关键）

| 风险因素 | 干预 |
|---------|------|
| **高血压** | 降压治疗（老年患者避免过度降压） |
| **糖尿病** | 血糖控制 |
| **高脂血症** | 他汀类药物 |
| **心房颤动** | 抗凝治疗（华法林 INR 2.0-3.0 或 DOACs） |
| **吸烟** | 戒烟 |
| **生活方式** | 规律运动、健康饮食、适度饮酒 |

### 2. 抗血栓治疗
- 动脉粥样硬化/腔隙性卒中：阿司匹林、氯吡格雷或**西洛他唑**（推荐用于小血管病变）
- 心源性栓塞：华法林或 DOACs

### 3. 对症药物治疗

| 症状 | 选择 |
|------|------|
| **认知损害** | 胆碱酯酶抑制剂（**加兰他敏**、多奈哌齐）用于轻中度 VaD；**美金刚**用于中重度 VaD |
| **抑郁** | SSRIs/SNRIs |
| **情感淡漠** | **金刚烷胺** |
| **激越/攻击** | 喹硫平（无糖尿病者） |
| **帕金森综合征** | 左旋多巴（疗效有限） |

### 非药物治疗
认知康复、物理/作业/言语治疗、照护者支持和教育

## 预后与病程

- **高度可变**: 经典为**阶梯样进展**（突发下降后平台期）
- 积极控制风险因素可**稳定甚至改善**部分患者
- 复发性卒中可致**快速进展**
- **混合病理（VaD + AD）** 预后常较单一病理更差
- **早期诊断和风险因素管理**可减缓进展、改善生活质量
- VaD 是**最可预防的痴呆类型**
