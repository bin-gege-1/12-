# 肌萎缩侧索硬化 (Amyotrophic Lateral Sclerosis, ALS)

## 疾病概述

ALS 是一种进行性、致死性神经退行性疾病，以**上运动神经元（UMN）和下运动神经元（LMN）**的选择性丢失为特征，导致进行性肌肉萎缩、瘫痪，最终因呼吸衰竭死亡。ALS 与额颞叶痴呆（FTD）构成临床-病理连续谱——高达 50% 的 ALS 患者出现认知/行为损害，约 15% 符合 FTD 诊断标准，两者共享 **TDP-43 病理** 和 **C9orf72** 基因突变。

## 流行病学

- **终生风险**: ~1:350（男性 1:300；女性 1:400）
- **男女比**: ~1.5:1（70 岁后趋于 1:1）
- **好发年龄**: 50-70 岁
- **中位生存期**: 诊断后 2-4 年
- **全球发病率**: ~1.68/10 万人年
- **家族性 ALS (fALS)**: 10-15%；**散发性 ALS (sALS)**: 85-90%
- **已知风险因素**: 年龄、男性、遗传、吸烟、军事服役、某些农药暴露

## 病理特征

### TDP-43 蛋白病
**TDP-43** (TAR DNA结合蛋白43) 病理存在于 **>97% 的 ALS 病例** 中，是 ALS 的病理标志。正常情况下 TDP-43 位于细胞核，病理状态下错误转位至细胞质并形成毒性聚集。值得注意的是，*TARDBP* 基因突变仅占 <1% 病例，说明非遗传因素驱动了大多数 TDP-43 病理。

### 核心分子机制

| 机制 | 描述 |
|------|------|
| **TDP-43 蛋白病** | 核转位至胞质、异常聚集、RNA 代谢失调 |
| **C9orf72 重复扩展** | 六核苷酸 GGGGCC 重复（最常见遗传病因，~40% fALS） |
| **SOD1 突变** | 功能获得性毒性，氧化应激 |
| **FUS 突变** | RNA 结合蛋白，液-液相分离缺陷 |
| **RNA 代谢异常** | 剪接缺陷、隐蔽外显子包含（*UNC13A*、*STMN2*） |
| **兴奋性毒性** | 谷氨酸/GABA 系统 E/I 失衡 |
| **核质转运缺陷** | 核孔复合体运输受阻 |
| **线粒体功能障碍** | SOD1 相关通路和代谢衰竭 |
| **神经炎症** | 小胶质细胞失调、调节性 T 细胞减少 |

### 遗传学
超过 40 个 ALS 关联基因已鉴定。四大核心基因: **C9orf72**（最常见）、**SOD1**、**TARDBP**、**FUS**。其他重要基因: TBK1、NEK1、CHCHD10。

## 临床表现

### 起病形式
- **肢体起病**（最常见）: 足下垂、手部无力、精细动作丧失
- **球部起病**（~25%）: 构音障碍、吞咽困难、流涎
- **呼吸起病**（罕见）: 端坐呼吸、呼吸困难

### 核心体征 — UMN + LMN 组合
| 上运动神经元 (UMN) 体征 | 下运动神经元 (LMN) 体征 |
|-------------------------|-------------------------|
| 痉挛状态 | 肌肉萎缩 |
| 腱反射亢进 | 肌无力 |
| 假性球麻痹（强哭强笑） | 肌束颤动 |
| Hoffmann/Babinski 征 | 腱反射减退 |

### 认知与行为
- 执行功能障碍、言语流畅性下降
- 情感淡漠、行为改变
- 假性球麻痹（**Nuedexta** 为其对症治疗）

## 诊断方法

### 诊断标准
| 标准 | 特点 |
|------|------|
| **修订版 El Escorial** | 按受累体区数分可能/很可能/确诊 |
| **Awaji-Shima** | 纳入电生理证据，提高灵敏度 |
| **Gold Coast (2019)** | 简化是/否框架，≥2 区 LMN 体征即可诊断，灵敏度最高 |

### 诊断流程
- 详细病史和神经系统查体（含家族史）
- **EMG/NCS** — 确认 LMN 受累；检测肌束颤动
- **MRI**（脑、颈、腰）— 排除结构性模拟病
- **实验室检查** — 排除 ALS 模拟病（CK 水平、自身免疫筛查）
- **基因检测** — 现建议所有确诊患者进行

### 新兴生物标志物

| 标志物 | 类型 | 用途 |
|--------|------|------|
| **NfL** (CSF + 血液) | 预后 | 最成熟标志物，与进展和生存相关 |
| **隐蔽肽** (UNC13A, STMN2) | 诊断 | 直接反映 TDP-43 病理，ALS 特异性高 |
| **外泌体** (TDP-43, pTDP-43) | 诊断/预后 | 可穿过 BBB |
| **壳三糖酶** (CHIT1, CHI3L1) | 预后 | 与快速进展和短生存期相关 |

## 治疗方法

> **无治愈方法。** 现有药物仅延长数月生存期。

### FDA 批准的疾病修饰治疗

| 药物 | 机制 | 关键证据 |
|------|------|----------|
| **利鲁唑** (Riluzole) | 抗谷氨酸/抗兴奋性毒性 | 延长生存期 ~3 个月（真实世界研究可能 6-18 个月）；全球唯一获批 |
| **依达拉奉** (Edaravone) | 抗氧化/自由基清除 | 延缓功能衰退，早期明确/很可能 ALS 患者获益最大 |
| **Tofersen** (Qalsody) | ASO 靶向 *SOD1* mRNA | 仅用于 **SOD1-ALS** 患者；降低 NfL 水平 |
| **AMX0035** (Relyvrio) | 苯丁酸钠+牛磺熊去氧胆酸 | 靶向内质网应激和线粒体功能障碍 |

### 对症治疗
- **Nuedexta**（右美沙芬/奎尼丁）— 假性球麻痹
- **无创通气 (NIV)** — 延长生存期约 13 个月，改善生活质量
- 多学科 ALS 门诊：神经科、呼吸科、营养科、康复科、心理社会支持
- 营养支持：吞咽管理、PEG/喂养管
- 物理和作业治疗：移动辅助、轮椅、家居改造
- 言语治疗和 AAC 交流设备

### 在研方向
基因治疗（ASO、RNAi、CRISPR/Cas9）、干细胞移植、免疫调节（Treg 治疗）、AI 驱动药物开发、精准医学多组学分型

## 预后与病程

- **中位生存期**: 2-4 年（球部起病更短）
- **长期生存**: ~10% 存活 >10 年
- **死亡原因**: 呼吸衰竭（最常见）；营养不良、感染
- **诊断延迟**: 平均约 12 个月
- **多学科综合照护** 是目前已证实对生存和生活质量影响最大的干预
