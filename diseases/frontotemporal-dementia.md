# 额颞叶痴呆 (Frontotemporal Dementia, FTD)

## 疾病概述

额颞叶痴呆是一组临床、病理和遗传异质性神经退行性疾病的统称，以额叶和/或颞叶进行性萎缩为特征。FTD 是**第二常见的早发型痴呆**（发病年龄通常 40-65 岁），是 65 岁以下人群痴呆的首要原因之一。其病理学名称 **额颞叶变性（FTLD）** 根据异常聚集蛋白分为多个亚型。FTD 与 ALS 构成临床-病理连续谱，二者共享 **TDP-43 病理** 和 **C9orf72** 基因突变。

## 流行病学

- **患病率**: 约 15-22/10 万
- **发病年龄**: 典型 40-65 岁（范围 20-80+）
- **中位生存期**: 症状出现后 3-7 年
- **男女比例**: 大致相等
- **遗传性**: >30% 有家族史，10-25% 呈常染色体显性遗传
- **主要遗传因素**: **C9orf72**（最常见，40% fFTD）、**MAPT**（tau 病理）、**GRN**（前颗粒蛋白，TDP-43 病理）

## 病理特征

### 分子分型（FTLD 病理分类）

| 病理亚型 | 聚集蛋白 | ~占比 | 相关临床表型 |
|---------|----------|-------|-------------|
| **FTLD-Tau** | 过度磷酸化 **tau** (3R/4R) | ~40% | bvFTD, nfvPPA, PSP, CBD |
| **FTLD-TDP** | **TDP-43** (A-E亚型) | ~50% | bvFTD, svPPA, FTD-ALS |
| **FTLD-FUS** | **FUS** | ~5% | 早发型 bvFTD，可极侵袭性 |

**Pick病** (FTLD-Tau, 3R tau 病): 球形胞质 tau 包涵体 (Pick小体)、额颞叶"刀锋状"萎缩，是 FTD 最早被描述的病理实体。

**CBD** 和 **PSP** 属于 4R tau 病，可表现为运动为主或以 FTD 为表型。

### 关键遗传基因

| 基因 | 病理关联 | 典型表型 |
|------|---------|---------|
| **C9orf72** | TDP-43 + DPR | bvFTD, FTD-ALS |
| **MAPT** | Tau | bvFTD, 右侧颞叶萎缩 |
| **GRN** | TDP-43 | bvFTD, PPA（不对称萎缩） |
| **TARDBP** | TDP-43 | FTD-ALS |
| **FUS** | FUS | 早发型 bvFTD |

## 临床表现

### 1. 行为变异型 FTD (bvFTD) — ~50-70%
- **脱抑制**: 社交不当行为、冲动、粗俗言语
- **情感淡漠**: 动机丧失、缺乏目标导向行为
- **共情丧失**: 情感冷漠、无法理解他人感受
- **刻板/仪式化行为**: 强迫性仪式、重复动作
- **口欲亢进/饮食改变**: 暴食、嗜甜、口探物体
- **判断力下降**: 冲动消费、财务管理不当
- **疾病感缺失**: 对自身改变缺乏洞察

**关键鉴别点**: 记忆和定向力早期相对保留，与 AD 不同。

### 2. 原发性进行性失语 (PPA) — 语言为主型

| 亚型 | 特征 |
|------|------|
| **非流利/语法缺失型 (nfvPPA)** | 费力断续言语、语法错误、口头失用 |
| **语义变异型 (svPPA)** | 流畅但空洞言语、词汇和物体含义丧失、命名障碍 |
| **少词型 (lvPPA)** | 单词提取障碍、句子复述差、语音错误；常与 AD 病理相关 |

### 3. FTD 合并运动神经元病 (FTD-ALS)
同时存在行为/认知下降和运动症状（肌无力、肌束颤动、吞咽困难），最常与 TDP-43 病理和 C9orf72 相关。

### 4. 右侧颞叶为主型 FTD (RATL)
新兴亚型：面容失认、行为改变、语义障碍、记忆障碍。最常关联 **TDP-43 C 型** 病理。

## 诊断方法

- **临床评估**: 详细病史（照护者报告至关重要）、神经系统检查
- **神经心理学测试**: ACE、NPI-Q、Iowa博弈任务、Mini-SEA 社会认知评估
- **MRI**: 额叶/颞叶不对称萎缩
- **FDG-PET**: 相应区域低代谢
- **CSF 生物标志物**: 主要用于排除 AD（纯 FTLD 中 Aβ/tau 正常）
- **基因检测**: 家族史阳性或早发型病例

## 治疗方法

> **无疾病修饰治疗获批。** 完全以对症支持为主。

### 非药物干预（核心）
环境调整、照护者教育和培训、言语治疗、认知刺激、运动、音乐/艺术治疗

### 药物治疗

| 症状域 | 选择 |
|--------|------|
| **抑郁/脱抑制** | SSRIs（一线） |
| **激越** | 曲唑酮 |
| **严重行为障碍** | 非典型抗精神病药（需谨慎——心血管/认知风险） |
| **认知** | 胆碱酯酶抑制剂和美金刚 **疗效有限**（与 AD 不同） |

### 新兴/实验方向
抗前颗粒蛋白抗体（GRN 相关 FTD）、tau 靶向治疗、LATE（边缘系统主导的年龄相关 TDP-43 脑病）生物标志物开发

## 预后与病程

- **中位生存期**: 3-7 年（变异大，FTD-ALS 最短）
- **进行性进展**: 自主生活能力逐渐丧失，晚期完全依赖
- **死亡原因**: 并发症（感染、营养不良、吞咽困难）
- **照护者支持是管理的基石**
