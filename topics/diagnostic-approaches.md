# 诊断方法总览 (Diagnostic Approaches)

## 概述

脑退行性疾病的诊断面临共同挑战：大多数疾病**缺乏单一定义性检测**，确诊依赖**死后神经病理学检查**。临床诊断基于临床表现、影像学、生物标志物和排除其他病因的综合判断。2025 年诊断领域的最大变革是**血液生物标志物的兴起**和**基于生物学的重新分类**。

## 1. 临床评估

### 病史
- 症状起病方式（隐袭 vs 急性、对称 vs 不对称）
- 进展速度（缓慢 vs 快速）
- 家族史（遗传模式线索——常染色体显性、隐性、散发）
- 既往病史（卒中、心血管、头部外伤、药物暴露）
- 照护者报告（对额颞叶痴呆等疾病感缺失患者至关重要）

### 神经系统检查

| 域 | 评估内容 |
|----|---------|
| **认知功能** | MMSE、MoCA、CDR |
| **运动系统** | 肌力、张力、反射、震颤、共济失调、步态 |
| **眼球运动** | 扫视、追踪、凝视——PSP（垂直凝视麻痹）、SCA2（慢扫视） |
| **颅神经** | 言语、吞咽、面部运动 |
| **自主神经** | 体位性血压、出汗、排尿功能 |

### 神经心理学测试
- **综合评估**: 记忆、注意、执行功能、语言、视空间、社会认知各域
- **关键区分**: AD（遗忘为主）vs FTD（执行/行为为主）vs DLB（注意力波动+视空间障碍）

## 2. 结构影像学

### MRI（核心工具）

| 疾病 | MRI 特征发现 |
|------|-------------|
| **AD** | 海马萎缩（内侧颞叶）、顶叶萎缩 |
| **FTD** | 额叶和/或颞叶不对称萎缩（"刀锋状"） |
| **DLB** | 内侧颞叶**相对保留**（与 AD 区分） |
| **VaD** | 白质高信号（FLAIR）、腔隙性梗死、微出血（T2*/SWI） |
| **PSP** | 中脑萎缩 → 矢状位**"蜂鸟征"**；MR 帕金森指数 (MRPI) |
| **MSA** | 脑桥**"十字面包征"**（T2 高信号）；壳核萎缩 |
| **CBD** | 额顶叶+基底节不对称萎缩 |
| **CJD** | **DWI 皮层缎带征 + 基底节/丘脑弥散受限** |
| **SCA** | 小脑 ± 脑干萎缩 |

## 3. 分子影像学

| 技术 | 示踪剂/用途 | 主要应用 |
|------|-----------|---------|
| **FDG-PET** | 葡萄糖代谢 | AD（颞顶叶低代谢）、FTD（额颞叶低代谢）、DLB（枕叶低代谢） |
| **淀粉样蛋白 PET** | florbetapir, flutemetamol | AD — 检测 Aβ 沉积；DLB — 排除或确认共病理 |
| **tau-PET** | flortaucipir 等 | AD — tau 沉积（与疾病分期相关）；4R tau 检测（PSP/CBD）尚不成熟 |
| **DaTscan SPECT** | ¹²³I-ioflupane | PD/DLB/MSA — 多巴胺转运体成像区分突触核蛋白病与特发性震颤/药物性帕金森综合征 |
| **MIBG 心肌显像** | ¹²³I-MIBG | PD/DLB（节后失神经）vs MSA（保留/正常）的鉴别 |

## 4. 脑脊液 (CSF) 生物标志物

| 标志物 | 应用疾病 | 临床意义 |
|--------|---------|---------|
| **Aβ42** (↓) | AD | 淀粉样蛋白沉积 |
| **p-tau181、p-tau217** (↑) | AD | tau 磷酸化；**p-tau217 诊断准确性最高** |
| **t-tau** (↑) | AD | 神经元损伤（非特异性） |
| **NfL** (↑) | 多种疾病 | 轴索损伤通用标志物；ALS、FTD、AD、CJD 中均升高 |
| **14-3-3** (↑) | CJD | 快速神经元损伤；灵敏度 87-92% |
| **RT-QuIC** | CJD、DLB/PD | 种子扩增试验检测 PrP^Sc（CJD 灵敏度 89.5-97%）或 α-synuclein |

## 5. 血液生物标志物 (2025 变革性进展)

| 标志物 | 应用疾病 | 状态 |
|--------|---------|------|
| **p-tau217** | AD | **2025年5月 FDA 批准首个商业检测** (Lumipulse G)；灵敏度 89-94%，特异度 90-96% |
| **p-tau181** | AD | 已验证；可区分 AD 与其他痴呆 |
| **Aβ42/Aβ40 比值** | AD | 与淀粉样蛋白 PET 阳性相关 |
| **NfL** | 多种疾病 | 轴索损伤通用标志物；ALS、FTD、CJD 中升高；非疾病特异性 |
| **GFAP** | AD、DLB | 星形胶质细胞激活标志物；与 Aβ 病理相关 |
| **外泌体标志物** | ALS、AD | 可穿过 BBB；携带 TDP-43、pTDP-43、NfL |

## 6. 电生理学

- **EEG**: CJD 周期性尖波复合波（PSWCs）、DLB 枕部慢波、CJD/AD 鉴别
- **EMG/NCS**: ALS — LMN 受累确认（肌束颤动、失神经电位）；MSA — 括约肌 EMG 神经源性改变
- **多导睡眠图 (PSG)**: DLB/PD — REM 睡眠无肌张力 (RWA) 确认

## 7. 基因检测

| 疾病 | 推荐检测基因 |
|------|-------------|
| **AD**（早发型/家族性） | *APP, PSEN1, PSEN2*；APOE 基因型 |
| **FTD** | *C9orf72, MAPT, GRN, TARDBP, FUS* |
| **ALS** | *C9orf72, SOD1, TARDBP, FUS, TBK1, NEK1* |
| **HD** | *HTT* CAG 重复数 |
| **SCA** | 共济失调重复扩展 panel（SCA1/2/3/6/7/8/10/17 + DRPLA） |
| **PD**（早发型） | *PRKN, PINK1, DJ-1, LRRK2, GBA* |
| **CJD** | *PRNP* |
| **VaD**（遗传型） | *NOTCH3* (CADASIL) |
| **朊蛋白病** | *PRNP* |

## 8. 其他

- **皮肤活检 (Syn-One)**: 检测磷酸化 α-synuclein，用于 DLB/PD（**医保覆盖**，~96% 准确率）
- **组织活检**: 脑活检（极少进行——仅用于疑似可治疗疾病如血管炎、CJD 确诊）；尸检（确诊金标准）
- **数字生物标志物**: 可穿戴设备、智能手机步态/震颤监测、VR 评估（研发中）

## 诊断策略分层

```
1. 临床评估（病史 + 神经系统检查 + 神经心理学测试）
                    │
2. 基础检查（血液常规、TSH、B12、MRI）
                    │
3. 基于怀疑方向的核心检测
   ├─ 认知为主 → CSF + PET（Aβ/tau） 或 血液 p-tau217
   ├─ 运动为主 → DaTscan、MIBG、EMG/NCS
   ├─ 快速进展 → EEG、CSF 14-3-3/RT-QuIC、DWI-MRI
   └─ 遗传性 → 基因检测（panel / 单基因）
                    │
4. 必要时 → 皮肤活检、PSG、tau-PET、α-synuclein SAA
```
