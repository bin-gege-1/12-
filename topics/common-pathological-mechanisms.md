# 共同病理机制 (Common Pathological Mechanisms)

## 概述

尽管脑退行性疾病在临床表现上差异巨大，它们在分子和细胞层面共享若干核心病理机制。理解这些共性有助于开发跨疾病适用的治疗策略。

## 1. 蛋白错误折叠与聚集

这是神经退行性疾病最核心的共性特征。每种疾病有其"标志性"聚集蛋白：

| 蛋白病类型 | 聚集蛋白 | 代表疾病 |
|-----------|---------|---------|
| **Tau蛋白病** | tau (3R/4R) | AD, PSP, CBD, Pick病(FTD) |
| **突触核蛋白病** | α-synuclein | PD, DLB, MSA |
| **TDP-43蛋白病** | TDP-43 | ALS, FTD (bvFTD, svPPA) |
| **PolyQ病** | 多聚谷氨酰胺蛋白 | HD, SCA1/2/3/6/7/17 |
| **朊蛋白病** | PrP^Sc | CJD, GSS, FFI |

### 共同机制
- **模板诱导的构象转换**: 错误折叠蛋白作为"种子"，诱导正常蛋白采用病理性构象
- **类朊蛋白样细胞间传播**: 聚集蛋白沿神经解剖通路从细胞传播至细胞（经外泌体、隧道纳米管、突触传递）
- **液-液相分离（LLPS）缺陷**: TDP-43 和 FUS 的应激颗粒持续存在，驱向不可逆聚集
- **翻译后修饰**: 磷酸化（如 tau p-tau217、α-synuclein Ser129）、泛素化、乙酰化调控聚集倾向

## 2. 氧化应激与线粒体功能障碍

- **线粒体复合物缺陷**: PD 中复合物 I 缺陷、HD 中复合物 II 缺陷
- **活性氧（ROS）过量产生**: 损伤脂质、蛋白和 DNA
- **线粒体自噬受损**: PINK1/Parkin 通路缺陷导致受损线粒体积聚
- **钙稳态失调**: 兴奋性毒性 → NMDAR 过度激活 → 钙超载 → 线粒体通透性转换孔开放
- **铁死亡 (Ferroptosis)**: 铁依赖性脂质过氧化细胞死亡，PD 和 HD 中均有证据

## 3. 神经炎症

- **小胶质细胞激活**: 从稳态（M2）转向促炎表型（M1）；释放 TNF-α、IL-1β、IL-6
- **星形胶质细胞增生**: GFAP 升高（现为 AD 的 AT(N)G 框架中的 G 组分）
- **NLRP3 炎症小体激活**: 在 AD、PD、VaD 中均有报道
- **血脑屏障（BBB）破坏**: 外周免疫细胞浸润、Aβ 清除受损
- **补体系统激活**: C1q 介导的突触修剪异常

## 4. 蛋白稳态网络崩溃

- **泛素-蛋白酶体系统（UPS）受损**: 错误折叠蛋白泛素化但降解受阻
- **自噬-溶酶体通路（ALP）缺陷**: GBA 突变损害溶酶体功能；mTOR 信号失调
- **内质网（ER）应激**: 未折叠蛋白反应（UPR）过度激活 → 凋亡
- **分子伴侣耗竭**: 热休克蛋白（HSPs）不足以应对蛋白聚集负荷

## 5. 兴奋性毒性

- **谷氨酸/GABA 失衡**: E/I（兴奋/抑制）平衡失调
- **NMDAR 过度激活**: 细胞内 Ca²⁺ 超载 → 线粒体衰竭 → 细胞死亡
- **NMDAR/TRPM4 死亡复合体**: AD 中新发现的关键兴奋性毒性介质
- **谷氨酸转运体（EAAT2/GLT-1）下调**: 突触间隙谷氨酸清除减少

## 6. 核质转运缺陷

- **核孔复合体（NPC）功能障碍**: C9orf72-ALS/FTD 的标志性机制
- **核浆转运蛋白异常**: TDP-43 核定位信号破坏 → 胞质转位
- **RNA 代谢失调**: 剪接缺陷、隐蔽外显子包含（*UNC13A*、*STMN2*）

## 7. 血管与胶质淋巴系统

- **胶质淋巴（glymphatic）清除受损**: 睡眠依赖的脑间质废物清除障碍
- **脑膜淋巴管功能障碍**: 大分子和免疫细胞引流受阻
- **BBB 完整性丧失**: 周细胞退变、紧密连接蛋白下调

## 治疗意义

这些共性机制意味着针对单个靶点（如抗 Aβ 单抗治疗 AD）的"魔弹"策略可能不足以应对复杂的病理网络。当前趋势趋向**多靶点联合治疗**：

- 抗蛋白聚集 + 抗炎 + 线粒体保护
- 药物 + 生活方式干预 + 神经调控
- 基于生物标志物的精准分型以匹配个体化治疗组合
