# 生物标志物 (Biomarkers)

## 概述

生物标志物（biomarker）是客观测量和评估正常生物学过程、病理过程或治疗反应的指标。在神经退行性疾病中，生物标志物对于**早期诊断、鉴别诊断、疾病监测和临床试验入组**日益重要。2024-2025 年的重大进展是**血液生物标志物获得与脑脊液和 PET 同等的诊断地位**。

## 各疾病的生物标志物汇总

### 阿尔茨海默病 — AT(N)(G) 框架 (NIA-AA 2024)

| 类别 | 含义 | CSF | 血液 | 影像 |
|------|------|-----|------|------|
| **A** | Aβ 沉积 | ↓Aβ42, ↓Aβ42/Aβ40 | ↓Aβ42/Aβ40 比值 | **淀粉样蛋白 PET (+)** |
| **T** | Tau 病理 | ↑**p-tau217**, ↑p-tau181 | ↑**p-tau217**（最高准确性） | **tau-PET** |
| **N** | 神经退行性变 | ↑t-tau | ↑**NfL**, ↑GFAP | MRI 萎缩, ↓FDG-PET |
| **G** | 神经炎症/胶质增生 | ↑YKL-40 | ↑**GFAP** | — |

**已获批**: p-tau217 血液检测 (Lumipulse G, FDA 2025年5月)

### 帕金森病与突触核蛋白病

| 标志物 | 类型 | 应用 |
|--------|------|------|
| **α-synuclein SAA (RT-QuIC)** | CSF | 检测病理性 α-synuclein（灵敏度 ~95%、特异度 ~97%） |
| **DaTscan SPECT** | 影像 | 基底节多巴胺转运体——区分神经退行性 vs 非退行性帕金森综合征 |
| **MIBG 心肌显像** | 影像 | 心脏交感神经支配——PD/DLB（↓）vs MSA（正常） |
| **皮肤活检 (Syn-One)** | 组织 | 磷酸化 α-synuclein 检测——**医保覆盖**，~96% 准确率 |
| **NfL** | CSF/血液 | 疾病严重度和进展 |

### ALS

| 标志物 | 类型 | 应用 |
|--------|------|------|
| **NfL** | CSF + 血液 | 最成熟的预后标志物；与进展和生存相关 |
| **隐蔽肽 (UNC13A, STMN2)** | CSF | 直接反映 TDP-43 病理——ALS 高特异性 |
| **壳三糖酶 (CHIT1, CHI3L1)** | CSF/血液 | 神经炎症标志物；与快速进展相关 |
| **外泌体 TDP-43/pTDP-43** | 血液 | 穿过 BBB；细胞类型特异性 |
| **Treg 细胞比例** | 血液 | 免疫调节治疗监测 |
| **尿 p75 / 新蝶呤** | 尿液 | 非侵入性；随疾病进展升高 |

### 朊蛋白病

| 标志物 | 类型 | 应用 |
|--------|------|------|
| **RT-QuIC** | CSF | 检测 PrP^Sc ——灵敏度 89.5-97%、特异度 ~100% |
| **14-3-3 蛋白** | CSF | 快速神经元损伤；灵敏度 ~87-92% |
| **DWI-MRI** | 影像 | 皮层缎带征 + 基底节/丘脑高信号——灵敏度 80-98% |
| **PSWCs** | EEG | 周期性尖波复合波——灵敏度 75-95% |

### 亨廷顿病

| 标志物 | 类型 | 应用 |
|--------|------|------|
| **mHTT** | CSF | 突变亨廷顿蛋白定量——治疗反应监测 |
| **NfL** | CSF/血液 | 疾病进展和发病预测——比临床量表更敏感 |
| **尾状核体积** | MRI | 萎缩速率——结构标志物 |
| **CAG 重复数** | 遗传 | 诊断确诊（≥40 = 完全外显） |

## 跨疾病通用标志物

| 标志物 | 来源 | 反映的生物学过程 | 主要应用疾病 |
|--------|------|-----------------|-------------|
| **NfL** | CSF/血液 | 轴索损伤（非特异性） | ALS, AD, FTD, CJD, HD, PSP, CBD |
| **GFAP** | CSF/血液 | 星形胶质细胞激活/神经炎症 | AD, DLB, FTD, TBI |
| **t-tau** | CSF | 神经元损伤/死亡 | AD, CJD, TBI |
| **pTDP-43** | CSF/外泌体 | TDP-43 病理 | ALS, FTD |
| **α-synuclein** | CSF/皮肤 | 突触核蛋白病理 | PD, DLB, MSA |

## 标志物级别定义

| 级别 | 定义 |
|------|------|
| **诊断性** | 确认疾病存在——如淀粉样蛋白 PET (+), CSF Aβ42↓, HTT CAG≥40 |
| **预后性** | 预测疾病进展——如 NfL, CHIT1, 尾状核体积 |
| **预测性** | 预测治疗反应——如 Treg 比例, mHTT |
| **药效学** | 靶点结合/通路调控证据——如 CSF p-tau 降低（抗 tau 治疗） |
| **安全性** | 不良反应监测——如 ARIA（MRI 监测抗 Aβ 治疗） |

## 生物标志物时间线（以 AD 为例）

```
临床前期（数十年）            MCI 期              痴呆期
    │                          │                    │
    ▼                          ▼                    ▼
Aβ42 ↓ (CSF)         p-tau ↑ (CSF/血)      认知下降 (临床表现)
淀粉样蛋白 PET (+)    tau-PET (+)           MRI 萎缩
                     NfL ↑ (血)             FDG-PET ↓
```

生物标志物异常遵循有序级联：**Aβ → tau → 神经退行性变 → 临床症状**。这使得临床前期检测和干预成为可能。

## 2025 关键趋势

1. **血液替代 CSF 和 PET** — 成本更低、创伤更小、可重复检测
2. **基于生物学的疾病分类** — 取代纯临床诊断（如 NSD 框架统一 PD+DLB）
3. **数字化和可穿戴标志物** — 步态、震颤、睡眠的实时持续监测
4. **多标志物联合** — 单一标志物不足以捕捉疾病全貌；panel 和算法组合是方向
5. **前驱期识别** — 在不可逆神经元丧失之前干预的治疗窗口
